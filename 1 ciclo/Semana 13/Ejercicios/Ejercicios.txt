Día de la semana
Solicita al usuario un número del 1 al 7 y muestra el día correspondiente.
Ejemplo: 1 → Lunes, 2 → Martes, ..., 7 → Domingo.
Si ingresa otro número, mostrar: "Día no válido".

Menú de operaciones matemáticas
Solicita dos números y después muestra un menú:
1. Sumar — 2. Restar — 3. Multiplicar — 4. Dividir.
Según la opción elegida, realiza la operación correspondiente. Si la opción no existe, mostrar "Opción no válida".

Mes del año
Solicita un número del 1 al 12 y muestra el nombre del mes correspondiente.
Ejemplo: 1 → Enero, 6 → Junio, 12 → Diciembre.
Cualquier otro valor debe mostrar "Mes no válido".

Clasificación de notas
Solicita una calificación usando una categoría: A, B, C, D o F.
Mostrar: A → Excelente, B → Muy bueno, C → Bueno, D → Debe mejorar, F → Reprobado.
Si se ingresa otra letra, mostrar "Calificación no reconocida".

Calculadora de áreas
Muestra un menú para elegir una figura: 1. Cuadrado, 2. Rectángulo, 3. Triángulo, 4. Círculo.
Según la opción, solicita los datos necesarios y calcula el área. Por ejemplo, para círculo solicita el radio; para triángulo, base y altura.

Tipo de usuario de un sistema
Solicita un número que represente el rol del usuario: 1 → Administrador, 2 → Empleado, 3 → Cliente, 4 → Invitado.
Muestra los permisos correspondientes a cada rol. Por ejemplo, el administrador puede gestionar usuarios y productos, mientras que el invitado solo puede consultar información.

Conversor de unidades
Solicita un valor y permite elegir una conversión: 1. Kilómetros a metros, 2. Metros a centímetros, 3. Kilogramos a gramos, 4. Horas a minutos.
Realiza únicamente la conversión seleccionada y muestra el resultado.

Menú de una tienda
Crea un pequeño menú de productos: 1. Laptop – S/ 2500, 2. Teclado – S/ 120, 3. Mouse – S/ 60, 4. Monitor – S/ 800, 5. Audífonos – S/ 150.
Solicita el código de un producto y la cantidad deseada. El programa debe mostrar el nombre del producto, precio unitario y total de la compra.

Sistema de transporte
Solicita al usuario seleccionar un medio de transporte: 1. Bus, 2. Taxi, 3. Bicicleta, 4. Metro, 5. Caminando.
Para cada opción muestra un mensaje diferente indicando una característica, por ejemplo costo, velocidad o impacto ambiental. Si el número no pertenece al menú, indicar "Transporte no disponible".

Cajero automático básico
   Simula un cajero con un saldo inicial de S/ 1000 y muestra: 1. Consultar saldo, 2. Depositar dinero, 3. Retirar dinero, 4. Mostrar datos de la cuenta, 5. Salir.
   Según la opción seleccionada, realiza la acción correspondiente. En depósito y retiro debes solicitar el monto; en el retiro, verifica que exista saldo suficiente. Para este ejercicio puedes usar la estructura múltiple para el menú y condicionales simples dentro de algunas opciones.
